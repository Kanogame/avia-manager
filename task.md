
1. Инициализация и интеграция с PhAB
Создать модуль main.cpp, который инициализирует Photon (PtInit), загружает сгенерированный код окна из wgt и запускает главный цикл обработки событий (PtMainLoop)
Получить указатели на ключевые виджеты (используя имена из палитры PhAB):

PtList — список самолетов

PtRaw — область для вида сверху

PtRaw — область для разреза по высоте.

PtButton — кнопка «Изменить курс» 

PtText — поля ввода для новых координат

2. Получение данных от сервера (IPC)
Протокол: Клиент подключается к серверу, используя нативный механизм QNX IPC.

Клиент создает канал (ChannelCreate) и ждет подключения от серверов-самолетов.

Каждый сервер должен зарегистрироваться у клиента, установив соединение (ConnectAttach).

В клиентской части должен быть реализован цикл приема сообщений (MsgReceive), который обрабатывает входящие данные от серверов:

Сообщение типа «Данные» (PlaneState): содержит ID самолета, координаты x, y, высоту.

Важно: Клиент не должен блокироваться в ожидании сообщений. Нужно использовать неблокирующий режим или отдельный поток для IPC, чтобы интерфейс оставался отзывчивым.

Отправка команд серверу: Использовать MsgSend для доставки на сервер структуры Command (изменить курс или аварийно завершиться). Для этого необходимо знать ID соединения (coid) для каждого самолета.

3. Хранение состояния и обнаружение коллизий
Реализовать класс PlaneController, который хранит std::map всех активных самолётов. Ключ — ID самолёта, значение — структура с координатами и статусом.

При каждом обновлении данных вызывать метод CollisionDetector::check(), который попарно сравнивает 3D-расстояния между самолётами:

Если dist < DANGER_ZONE → установить статус WARNING (жёлтый).

Если dist < CRASH_ZONE → установить статус CRASH (красный) и немедленно отправить команду CMD_CRASH соответствующим серверам.

4. Визуализация (Отображение на виджетах PtRaw)
Написать две функции отрисовки, которые вызываются по таймеру (с помощью PtTimerCreate). Внутри функций использовать только функции семейства Pg* (Photon Graphics) для рисования.

Функция №1: Вид сверху (DrawRadar):

Отобразить прямоугольную зону обслуживания.

Нарисовать каждый самолёт в виде треугольника, ориентированного по направлению его движения.

Закрасить треугольник в зависимости от статуса (зелёный — норма, жёлтый — опасно, красный — авария).

Функция №2: Разрез по высоте (DrawAltitude):

Нарисовать оси координат (X — горизонтальная дальность от условного центра, Y — высота).

Отобразить самолёты в виде кружков, соблюдая масштаб по высоте.

5. Интерактивность и управление
Реализовать заполнение виджета PtList при получении новых данных. Для добавления элементов используй функцию PtListAddItems.

Совет: Внутри callback-функции для отрисовки списка можно добавить иконки, обозначающие статус самолёта (цветной круг), для быстрого визуального восприятия.

Выбор самолёта: Подключить callback на событие Pt_CB_SELECTION для PtList. При клике на строку сохранять ID выбранного самолёта.

Изменение курса: При нажатии на кнопку «Изменить курс»:

Считать координаты X и Y из полей PtText.
Сформировать структуру Command с типом CMD_CHANGE_DIR для выбранного ID.
Отправить её соответствующему серверу через MsgSend.
Ввод с клавиатуры: Добавить обработчик, чтобы диспетчер мог вводить координаты, не используя мышь.

Завершение работы: При закрытии окна корректно завершить все IP-соединения и освободить ресурсы.
